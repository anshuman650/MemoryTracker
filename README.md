# 🧠 MemoryTracker

**MemoryTracker** is a Python-based desktop application for monitoring memory usage, detecting leaks, and visualizing garbage collection activity in real-time. It's designed to help developers and system administrators keep an eye on memory consumption across processes.

## 📦 Features

- 📊 **Dashboard View**: Visual summary of memory usage
- 🔁 **Garbage Collector Monitor**: Track GC events live
- 🕵️ **Leak Detector**: Spot memory leaks in running processes
- 🧩 **Process Tracker**: Detailed memory breakdown per process
- ⚙️ **Customizable UI**: Themes and icon support
